# SwimTrack V2.1 — Android + iOS Sideload

A pasta `ios/` contém uma segunda via nativa para iPhone, preparada para SideStore/AltStore.

Funcionalidades iOS incluídas:
- perfil editável;
- género, clube, ano, época e escalão;
- cálculo automático de escalão;
- Constança 2010 / época 2026 -> Júnior Feminino 1.º ano;
- importação de PDF Swimrankings com PDFKit;
- leitura de piscina curta e longa e melhores tempos;
- inserção manual de tempos;
- TAC e comparação Qualificada/Falta;
- TAC editáveis;
- evolução entre importações;
- dados persistentes localmente;
- ícone original reutilizado no iOS;
- workflow GitHub para IPA SideStore/AltStore.


## V2.2 — Calendário e Swimrankings
